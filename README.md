# Power BI Sales Dashboard

## Project Overview

This project is an interactive Power BI sales dashboard designed to analyze sales performance and customer behavior using transactional sales data.

The dashboard provides a comprehensive view of key business metrics including total sales, units sold, total transactions, average sales, sales trends, geographic distribution, product/model performance, payment methods, customer ratings, and brand-level performance.

The objective of this project is to transform raw sales data into meaningful business insights that can support data-driven decision-making.

## Dashboard Features

### Key Performance Indicators

The dashboard provides an overview of:

- Total Sales
- Total Units Sold
- Total Transactions
- Average Sales

### Sales Trend Analysis

The dashboard analyzes sales performance over time using monthly and daily trends, helping identify changes in sales activity and business performance.

### Geographic Analysis

A map visualization is used to analyze sales distribution across different cities and identify geographic patterns.

### Product/Model Analysis

The dashboard highlights the top-performing mobile models based on sales and helps identify products contributing significantly to overall revenue.

### Payment Method Analysis

Transaction distribution is analyzed across different payment methods to understand customer payment preferences.

### Customer Rating Analysis

Customer ratings are visualized to understand customer satisfaction and identify rating patterns.

### Brand Performance

A detailed table provides brand-level analysis including:

- Total Sales
- Units Sold
- Total Transactions

## Key Business Questions

The dashboard is designed to answer questions such as:

- What is the overall sales performance?
- How many units have been sold?
- How many transactions have been completed?
- Which products/models generate the highest sales?
- Which brands perform best?
- How do sales change over time?
- Which cities contribute to sales?
- Which payment methods are most frequently used?
- What are the customer rating patterns?
- Which brands generate the highest transaction volume?
